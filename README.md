# FireEvacuation

Минимальная структура Unity-проекта для MVP VR-симуляции эвакуации пострадавших.

## Структура папок

- `Assets/Scenes` — сцены проекта.
- `Assets/Scripts/Core` — базовая логика приложения.
- `Assets/Scripts/NPC` — логика NPC и пострадавших.
- `Assets/Scripts/VR` — VR/XR-взаимодействие.
- `Assets/Scripts/Scenario` — сценарии эвакуации и состояние симуляции.
- `Assets/Scripts/Logging` — логирование событий и действий.
- `Assets/Prefabs/NPC` — префабы NPC.
- `Assets/Prefabs/Environment` — окружение и элементы уровня.
- `Assets/Prefabs/Interaction` — интерактивные объекты.
- `Assets/Prefabs/Scenario` — сценарные префабы.
- `Assets/Configs` — конфигурационные ассеты и ScriptableObject-настройки.
- `Assets/Materials` — материалы проекта.
- `Assets/Logs` — лог-файлы и вспомогательные данные для отладки.

Существующие сцены, XR Rig и настройки проекта не изменялись.
